# FlashMeow —— 鸿蒙社交聊天项目

## 项目简介

FlashMeow 是基于鸿蒙操作系统（HarmonyOS）开发的智能社交聊天应用，聚焦于即时通讯、语音消息、智能语音识别、联系人管理、朋友圈动态等功能，致力于为用户带来高效、便捷、智能的社交体验。

## 主要功能

- **即时聊天**：支持文本、语音等多种消息类型，长按录音、语音转文字、语音播放等交互。
- **联系人管理**：分组、搜索、添加联系人，支持字母索引快速定位。
- **朋友圈动态**：浏览好友动态，支持多媒体内容展示。
- **发现与智能体**：集成智能体推荐、AI工具、效率办公等分类，支持 WebView 智能体运行。

## 主要页面与组件

- **首页（Home）**：展示最近聊天列表，点击进入聊天详情。
- **聊天页（ChatPage）**：支持文本、语音、表情等多种消息类型，集成语音识别与录音功能。
- **联系人页（Contact）**：分组展示联系人，支持字母索引快速跳转。
- **朋友圈（CirclePage）**：浏览好友动态，支持多媒体内容。
- **发现页（DiscoveryComponent）**：智能体推荐、AI工具分类、轮播图等。
- **我的页（Mine）**：个人信息、二维码、收藏、设置等入口。
- **搜索页（SearchPage）**：支持内容搜索与分类入口。
- **核心组件**：如聊天气泡、联系人项、智能体卡片、分类组件等，均支持复用和扩展。

## 技术实现

- **前端框架**：ArkUI（鸿蒙官方UI框架）
- **音频处理**：基于 `@kit.AudioKit` 实现录音、播放，录音文件带有精确时间戳
- **语音识别**：集成 `SpeechRecognizerManager` 实现语音转文字
- **本地存储**：使用 `PreferenceUtils` 管理用户信息与本地数据
- **页面导航**：支持组件导航与页面路由
- **权限管理**：通过 `PermissionUtils` 动态申请与校验麦克风、存储、相机等权限
- **网络请求**：集成 `@ohos/axios` 实现后端接口通信
- **硬件能力**：支持设备信息、网络、传感器等能力获取

   ```bash
   npm install
   ```

3. **运行项目**  
   - 使用 DevEco Studio 打开项目
   - 选择模拟器或真机，点击运行
